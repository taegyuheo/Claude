# CLAUDE.md — 결과물 생성 지침

`upload/` 의 C 소스 하나를 **2분할 인터랙티브 HTML**(왼쪽 코드 / 오른쪽 분석 카드) 한 장으로 만든다.
만드는 절차, 데이터 형식, 내용 작성 기준은 **`tools/작성방침.md`** 에 있다. 새 파일을 다루기 전에 먼저 읽는다.

---

## 1. 폴더 구조

```
Claude/
├── upload/        원본 코드 (.c / .h) — 읽기 전용 (upload/src/ 아래에 있어도 됨)
├── result/        결과물 <이름>.html — build.sh 가 만든다
├── tools/
│   ├── 작성방침.md            절차 · 데이터 형식 · 작성 기준 · 배포 방법
│   ├── viewer_template.html   공통 엔진 (화면, 구문 강조, 카드 그리기)
│   ├── build.sh               합치기 + 검증
│   ├── example/example.c      기준 예시 원본
│   └── data/
│       ├── example.js         기준 예시 데이터 (새 파일은 이것을 복사)
│       └── <이름>.js          분석 대상별 데이터 (카드 내용)
└── CLAUDE.md      이 파일
```

## 2. 파일 보호 규칙

- `upload/` 안의 파일은 **수정·삭제·이동하지 않는다.** 빌드 산출물도 만들지 않는다.
- 결과물은 **`result/`** 에만 만든다. `result/*.html` 은 직접 고치지 않는다 (다음 빌드에서 사라짐).
- 중간 작업 파일(스크린샷 등)은 `result/` 가 아닌 임시 폴더에 둔다.

## 3. 만드는 방법

1. `tools/data/example.js` 를 복사해 `tools/data/<이름>.js` 를 만들고 내용을 채운다 (형식이 헷갈리면 example.js 의 같은 종류 심볼을 따른다)
2. `bash tools/build.sh <파일>.c` — 원본 삽입, 원본 일치 확인, 브라우저 실행 확인, 카드 빠진 함수 경고
3. 스크린샷과 대표 함수 카드(`result/<이름>.html#심볼키`)를 눈으로 확인한다

| 요청 범위 | 고칠 곳 |
|---|---|
| 파일 하나의 내용 | `tools/data/<이름>.js` → 그 파일만 빌드 |
| 모든 결과물의 화면이나 카드 틀 ("앞으로", "모든") | `tools/viewer_template.html` → **모든 결과물 다시 빌드** → `작성방침.md` 와 이 파일도 갱신 |

## 4. 결과물 규칙

### 화면
- 단일 `.html` 파일. Tailwind CSS CDN(버전 고정) + Vanilla JavaScript. 다른 라이브러리는 쓰지 않는다
- 왼쪽: 소스 전체, 구문 강조, 함수·변수·매크로·상수·연산자를 클릭 가능하게, 줄 왼쪽 색 띠로 역할 표시
- 오른쪽: 처음엔 **전체 개요**, 심볼을 클릭하면 **상세 카드**. `Esc` 나 "전체 개요" 버튼으로 돌아감

### 코드 뷰어의 주석
- **파일 머리 주석(첫 `#include` 위)만 표시**하고 나머지 주석은 지운다 (엔진이 자동 처리)
- 주석만 있던 줄은 숨기고, **줄 번호는 원본 번호 그대로** (번호가 건너뜀). 원본 파일은 건드리지 않는다

### 전체 개요 — 함수·변수·흐름만
- 넣는 것: 한 줄 요약 / (선택) 루프 시뮬레이션 / 실행 흐름(역할별 구간, 클릭하면 해당 줄로 이동) / 보는 법
- **넣지 않는 것**: 하드웨어 계층도, 객체 수명 표, 레지스터 바로가기

### 함수 카드 — 고정 틀 (모든 칸 필수)
1. 배지(함수 + 역할), 이름, 함수 원형, 한 줄 요약, 등장 줄
2. **📥 파라미터 표**: 이름 | 타입 | 이 코드에서 넘긴 값 | 설명 (없으면 "파라미터 없음")
3. **📤 리턴값 표**: 값 | 의미 | 이 코드에서의 처리 (확인하지 않으면 "확인하지 않는다")
4. **⚙ 동작**: 짧게
5. **⚠ 실패 원인 분석 표**: 원인 | 증상 / errno | 이 코드에서 일어나는 일 | 대처
6. **🔗 관련 변수·상수**, **🔗 관련 함수**: 항목마다 관계를 한 줄로. 코드 화면에도 노란 점선 테두리로 표시
- 함수 카드에는 **레지스터 정보(그림, 비트 연산, 주소)를 넣지 않는다**

### 변수 · 매크로 · 상수 카드
- 고정 틀이 아직 정해지지 않았다. 현재는 `example.js` 형식(자유 섹션 + 관련 심볼)을 따른다

### 문장
- 한국어, 짧은 평서문. 용어는 처음 나올 때 풀어 쓴다
- 일반론보다 **이 코드의** 실제 값, 실제 줄 번호, 실제 흐름을 쓴다

## 5. 환경

- Windows + Git Bash. `build.sh` 는 Chrome 또는 Edge 헤드리스로 검증한다
- 대상 보드나 라이브러리가 없어 코드를 실행할 수 없는 경우가 많다. 실행해서 확인하지 못한 동작은 추정이라고 밝힌다
- 원본 소스의 줄바꿈이 CRLF 여도 엔진이 처리한다
